# Utilisation

depuis le fichier *docker-compose.yml* au niveau du root,

```
docker compose up --build 
```

Ensuite aller sur [localhost:8000](http://localhost:8000)

Pour ajouter des fichiers, appuyer sur le boutton sélection de fichier

-> sélectionner un ou plusieurs fichier <br />
-> appuyer sur upload <br />
-> appuyer boutton retour pour revenir au tableau </br>

# Utilisation

depuis le fichier *docker-compose.yml* au niveau du root,

```
docker compose up --build 
```

Ensuite aller sur [localhost:8000](http://localhost:8000)

Pour ajouter des fichiers, appuyer sur le boutton upload
-> sélectionner un ou plusieurs fichier 
-> appuyer sur upload
-> boutton retour retour pour revenir au tableau
